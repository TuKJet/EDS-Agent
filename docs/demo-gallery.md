# 发动机 CAD 与多 Die 液冷 CAE 案例

更新日期：2026-11-12。README 展示发动机和液冷对比的循环 GIF，本页保存过程、比较条件与证据边界。案例分别来自 2026-11-09 起的发动机任务，以及 2026-11-10 至 12 日持续迭代的 COMSOL 多 Die 液冷任务。

## 1. CAD：约 2.0 L 直列四缸发动机

[发动机运行与爆炸展示（GIF）](media/demos/engine-motion-exploded.gif)

该案例从简单机芯扩展到有外壳、附件和显示状态的产品概念装配：

| 内容 | 实际交付与核验 |
| --- | --- |
| 几何参数 | 缸径 86 mm、行程 86 mm、连杆中心距 143 mm，四缸总排量约 2.0 L |
| 装配 | 37 种原生零件、116 个组件、36 个原生配合 |
| 产品表达 | 缸体外壳、缸盖罩、油底壳、正时罩等；外观与剖视运动显示状态 |
| 运动 | 原生 Motion Study：30 rpm、4 s；曲轴、连杆、活塞及凸轮轴联动 |
| 回读验证 | 33 个运动采样点；86 mm 行程、143 mm 连杆长度、销轴对齐、1/4 缸和 2/3 缸各自同相、凸轮轴半速 |
| 交付重开 | 打包依赖后重新打开并计算运动；保存的原生马达及配合可复用，运动缓存需重算 |

展示按“运行 → 停机 → 整体外观 → 零件展开”组织。本次通过 VM1 的 SolidWorks MCP 重新连接并核验原生装配，在完整副本中重新计算 Motion Study、由 SW 导出图像帧。运行段仅隐藏朝向镜头的缸体、缸盖罩、凸轮轴罩和油底壳四片半壳，保留背侧外壳、缸套、进气附件及其他原本可见的组件；每次运动定位后重新设置并回读可见组件，确认相对完整外观仅少这四片半壳。停机后再恢复完整外观。爆炸阶段使用 SW 的 `PresentationTransform` 展示变换，回读组件展示位移并检查底层装配姿态保持不变；视频后处理只添加字幕、缩放和压缩。

爆炸图用于辨认组成与空间关系，不证明实际拆装顺序、工具可达性或装配无干涉。媒体的制作方式、输入哈希与验证见[发布清单](media/demos/manifest.json)。

**工程边界：** 气门仍是静态示意，未验证燃烧、润滑、热管理、强度、材料、公差和制造性。后续虽输出了 37 种零件、41 页几何复核图册并核查 145 条尺寸，仍未达到约 2.0 L 真实发动机的制造放行要求；不能将这部分记录表述为“已完成可加工发动机”。

## 2. CAE：双四层堆叠液冷优化

[液冷对比动画（GIF，约 4.36 MB）](media/demos/liquid-cooling-comparison.gif)

GIF 由同一视频缩放为 960 × 720、6 fps、96 色，保留完整时序并循环播放；
仅调整展示编码，不改变物理求解数据或动画时间含义。

任务从多 Die 液冷演示扩展到两组四层堆叠：8 个 Die、总热功率 600 W。研究既比较结构，也修复模型和数值验证问题；失败、未运行分支与被采纳的结果分别保留。

### 结构迭代与比较口径

```mermaid
flowchart LR
    A["A 浅直道：600 W 热收支未通过"] --> B["B 加深直通道：合格参考"]
    B --> E["E 624 根整齐铜柱：匹配冷板液压功率"]
    E --> V["两网格筛选与压力阶次复核"]
    V --> T["B/E 真实热启动：同步对比动画"]
```

数值修复与结构设计分开记录：原生端口、含惯性流场、P1 热离散、能量收支、温度下冲、出口回流和混合单元检查支撑比较的可信度，不作为新结构收益来计算。中央供液 C、薄 TIM D 尚未运行；交错柱阵 F 完成几何/网格检查但未完成流热求解；高密度柱阵 G 未冻结、未运行，均不计为已证实的改进。

主比较固定入口 25℃、额定发热 600 W、恒物性单相水模型，匹配冷板液压功率 `Δp × Q ≈ 0.008519 W`，而非固定体积流量或整泵电功率。

| 指标 | B 加深直通道 | E 整齐铜柱 |
| --- | ---: | ---: |
| 流量（L/min） | 1.2000 | 0.4161 |
| 压降（Pa） | 425.96 | 1227.62 |
| 冷板液压功率（W） | 0.00851924 | 0.00851284 |
| 最高 Die 温度（℃） | 167.84 | 153.27 |
| 相对入口的峰值温升两网格变化 | 1.76% | 0.52% |

主比较最高温降低 **14.57 K**，相对入口的峰值温升降低约 **10.20%**。E 的速度/压力阶次 P2/P2 交叉复核得到 **155.55℃**，比主 E 高 **2.28 K**，仍比 B 低 **12.29 K**；温度离散仍为 P1。B 没有完成同样的阶次矩阵，因此这只是非对称的方法敏感性复核，不是完整阶次收敛或统计置信区间。

两网格属于有界敏感性筛选，不等同 GCI 或渐近收敛验证。铜柱方案的核心湿面积比 B 少 16.75%，本结果不支持“因为换热面积增大所以降温”的归因。尚未完成硬件验证、时间步加密或尾流稳定性验证，也不声称达到全局最优。

### 动画怎样对应真实计算

| 画面 | 数据与观看方式 |
| --- | --- |
| 上方材料与流向俯视图 | 铜色表示翅片/铜柱、蓝色表示液体，白色移动箭头依据 COMSOL 稳态速度场；颜色用于辨认材料 |
| 下方温度剖视图 | 固体与流体温度来自原生热瞬态解；两方案使用同一物理时钟及固定 24.5–175℃ 色标 |
| 开机阶段 | 初始与入口均为 25℃，0.5 s 内升到 600 W；已计算 0–20 s、每 0.2 s 保存一组解 |
| 视频节奏 | 4 s 开场 + 24 s 展示物理时间 0–3 s（慢放 8 倍）+ 4 s 稳态结果对比；播放帧只在已有解之间插值 |
| 剖切与示踪 | 移除上盖/局部结构以露出四层 Die；温度视图竖向放大 3 倍；示踪点不按质量或热量加权，热流箭头长度归一化 |
| 结尾 | 使用 COMSOL 原生热点导出图，主比较数值来自结果记录而非图像估读 |

这是**真实热瞬态 + 已建立并固定的稳态流场**，不是流体从静止启动的全耦合瞬态。展示由 COMSOL 数据后处理合成，并非全片软件录屏；B/E 的 20 s 最高温分别为 167.83818℃、153.26970℃，累计能量残差比例约为 0.0139%、0.2567%。这些检查支持本例的限定解释，不代替时间收敛或实测校准。

原交付对代表帧、结构可辨识性、移动流向、温升变化、原生颜色样本与整段媒体解码做过验收。本次保留原封面，将已认可的动画转为约 4.36 MB 的循环 GIF，保留完整 32 秒内容；记录来源与 GIF 的 SHA-256，检查转换后代表帧和全部 193 帧解码。转换只改变媒体编码、帧率与分辨率，不重算场数据；原始工程媒体继续留在本地，公开展示目录不再保留 MP4 副本。

### 归档与后续复用

Study 保存完整实验、Run、证据和 Assessment；有意义的迭代投影到中央 feedback。完整执行溯源图与精选知识图分开，失败、未知及未运行状态保留，工具调用不会自动变成通用方法。新工程先检索少量固定版本方法，再检查条件；热流数值不能直接作为磁场或磨损模型依据。通用的控制变量、验证和可读性流程可在重设观测量与判据后复用。
