## 修改结果

- `eds-study` 保留紧凑入口，正常 MCP 调用与安装排障分成独立参考。正常调用先发现已有配置，只读取目标任务的上游章节、能力行及必要参考；安装、认证、传输与版本问题分别路由。远程服务不要求调用者本机安装 COM 环境。
- `execution` 仍完整核对本地来源、补丁和绑定，默认输出简短结果；显式 `--full` 才展示详细补丁诊断。本地状态不等于远端部署或连接状态。
- 知识按设计、方法、实验方案、反馈、偏好五类逻辑组织，共用原有 Markdown/SQLite。问题优先于阶段，显式 `--type` 可作有意的跨类查询；零命中不自动扩大检索。
- 默认 `read` 返回目标单元全文和关联定位。正文保留公式、单位和条件；关联正文使用显式关系类型、深度和数量限制读取。省略、循环、缺失与截断可见。
- 偏好独立记录主体、适用项目/问题、确认状态及来源。候选不能自动成为已确认偏好；同范围明确修订可替代旧记录，历史仍可按版本读取；冲突返回有限定位，不突破搜索结果数量限制。
- 各类别的内容纳管约定放入独立参考，检索时不加载完整提取模板。代码校验共同字段和偏好合同，工程意义仍由 Codex 检查。

## 兼容性与边界

旧知识 Markdown 和显式登记/索引/重建机制保留；旧无路由搜索仍可用于有意的全库检索。
依赖 `read()` 自动返回关联全文的调用需要改成显式 `depth`/`relation_types`，或按固定 id/version 另行读取。
新偏好单元需要专属字段；本次未推断或登记真实用户的新偏好。

偏好范围筛选是检索适用性规则，不是文件访问控制；显式固定 id 回读允许历史审查，保密资料应使用独立授权根目录。
本轮证明本地路由、数据处理和资料读取路径可用，不声称上下文开销已最优、模型质量有量化提升，也不新增实机工程验收结论。原 AC-07/AC-10 的未执行/用户跳过状态保持原记录。
